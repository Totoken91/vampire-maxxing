# SPEC — i18n

## Stratégie

Dict typé maison. Pas de lib. Build-time typesafe.

## Structure

```
src/i18n/
├── index.ts        ← API publique, détection langue, getter
├── en.ts           ← dict anglais (source of truth)
├── fr.ts           ← dict français
└── keys.ts         ← types dérivés
```

## index.ts

```ts
import { en } from './en';
import { fr } from './fr';
import type { Dict, Key } from './en';

let currentLang: 'en' | 'fr' = 'en';
const dicts = { en, fr };

export function setLang(lang: 'en' | 'fr'): void {
  currentLang = lang;
  document.documentElement.lang = lang;
  // Emit event pour que les composants refresh
  window.dispatchEvent(new Event('lang-change'));
}

export function getLang(): 'en' | 'fr' {
  return currentLang;
}

export function t(key: Key, vars?: Record<string, string | number>): string {
  let str = dicts[currentLang][key] ?? key;
  if (vars) {
    for (const [k, v] of Object.entries(vars)) {
      str = str.replace(`{${k}}`, String(v));
    }
  }
  return str;
}

export function detectBrowserLang(): 'en' | 'fr' {
  const lang = navigator.language.toLowerCase();
  if (lang.startsWith('fr')) return 'fr';
  return 'en';
}
```

## Usage dans les composants

```ts
import { t } from '../i18n';

const title = t('bloodline.label');
const tagline = t('form.lordOfNight.tagline');
const ascendSub = t('action.ascendSub', { n: 8 });
```

## Refresh dynamique

Au change de langue, l'event `lang-change` est dispatch. Chaque composant s'y abonne via `addEventListener` et appelle `update()`.

## Tips pour la trad FR

- **Conserver le feeling gothique-semi-ironique**. Les expressions mémées Gen Z doivent trouver un équivalent FR naturel.
- Ex : "based and bloodpilled" → "basé et sanginifié" (néologisme qui passe bien FR)
- Ex : "built different fr" → "construit différemment srx" ou garde en anglais si lisible
- Ex : "the mewing worked" → "le mewing a marché" (anglicisme déjà utilisé en FR Gen Z)
- **Le titre de jeu reste "Vampire Maxxing"** dans les deux langues (c'est un brand)

## Ajout d'une nouvelle langue

1. Créer `src/i18n/[lang].ts`
2. Copier depuis `en.ts`, traduire
3. Ajouter dans `index.ts` dans `dicts`
4. Tester : switch via settings, vérifier toutes les strings apparaissent
